Read the blueprint's palette and subtitle first (they are the brief, not a suggestion). Pull type/spacing scale and component grammar from exactly one Awesome Design style file; never reuse that file across other projects in the volume. Write the decision to design/art-direction.md: palette, type pairing, nav metaphor, and one sentence on why a sibling project could not swap in this identity.
